
# 🎯 Number Guessing Game (HTML, CSS, JavaScript)

This project is a **Number Guessing Game** built using **HTML, CSS, and JavaScript**.  
The player has to guess a randomly generated number between **1 and 100** within a limited number of attempts.

The game provides feedback after every guess to help the player reach the correct number.

---

## 🚀 Project Overview

The objective of the game is simple:
- The system generates a random number.
- The player tries to guess the number.
- The game provides hints whether the guess is too high or too low.
- The player wins if the correct number is guessed within the allowed attempts.

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & layout
- **JavaScript (Vanilla JS)** – Game logic

---

## ✨ Features

- Random number generation
- Limited attempts system
- Previous guesses tracking
- High / Low hint system
- Win and lose conditions
- Simple and interactive UI
- Responsive design

---

## 🧠 Game Logic

- A random number between 1 and 100 is generated.
- User submits a guess.
- The program checks:
  - If the guess is correct → Player wins
  - If too high → Hint displayed
  - If too low → Hint displayed
- Game ends after maximum attempts.
